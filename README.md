# 机动车年检查询器

一款根据车辆注册日期与车辆类型，精确推算年检周期的 Android 应用。

## 功能

- **年检周期推算**：按 2022 年 10 月新规计算，覆盖非营运小微型客车、面包车、营运载客、载货汽车、摩托车、教练车等车型
- **免检判定**：自动识别第 2/4/8 年免检申领标志与第 6/10 年上线检测
- **报废预警**：临近报废 12 个月内橙色提示，达到报废年限红色告警并给出办理流程
- **时间轴展示**：完整展示各周期节点，支持动态延伸到报废年限
- **车辆管理**：保存车牌号、车主、使用性质，支持拖拽排序与长按编辑
- **日历提醒**：一键创建年检提醒，附查询结果图片
- **双语主题**：液态玻璃风格，完整适配深色与浅色模式

## 技术栈

- Kotlin + Jetpack Compose
- 原生 SQLite（SQLiteOpenHelper）
- Material 3 设计规范

## 构建

```bash
./gradlew :lib:assembleDebug
```

产物位于 `lib/build/outputs/apk/debug/`
